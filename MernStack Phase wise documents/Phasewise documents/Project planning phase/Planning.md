
# Phase 3: Project Planning Phase - HouseRent Portal
## 1. SDLC Methodology
The project follows the *Agile Methodology*. Development is split into 2-week sprints to ensure continuous feedback, design iterations, and robust component development.
## 2. Project Milestones & Timeline

| Milestone | Phase | Key Deliverables | Duration |
| :--- | :--- | :--- | :--- |
| *Milestone 1* | Requirement & Planning | SRS Document, Architecture design, Database Schema | Week 1 |
| *Milestone 2* | UI/UX Design & Frontend | Component layout, Tailwind CSS setup, Responsive Views | Week 2-3 |
| *Milestone 3* | Backend & Database | MongoDB models, Express routes, JWT auth endpoints | Week 4 |
| *Milestone 4* | Integration & Testing | API wiring with React, state management, bug fixing | Week 5 |
| *Milestone 5* | Deployment & Review | Deployment on Render/Vercel, Project documentation | Week 6 |
