
# Phase 2: Requirement Analysis - HouseRent Portal

## 1. System Requirements

### A. Hardware Requirements
* *Processor:* Dual Core i3 / i5 or higher
* *RAM:* Minimum 8 GB RAM
* *Storage:* 20 GB free disk space

### B. Software Requirements
* *Operating System:* Windows 10/11, macOS, or Linux
* *Environment:* Node.js v16.x or above
* *Database:* MongoDB Atlas (Cloud Database)
* *IDE:* Visual Studio Code (VS Code)
* *Version Control:* Git & GitHub

## 2. Functional Requirements

### Module 1: Common / Public Module
* User Registration & Role Selection (Owner / Renter)
* Secure Login with password hashing
* Forgot Password with email verification
* Responsive landing page with search bar

### Module 2: Owner Module
* Upload property details (images, price, location, rules)
* View and edit active property listings
* Approve or decline booking requests from renters

### Module 3: Renter Module
* Search properties by location and budget
* Send instant booking/rent requests to owners
* Track application status on the dashboard

### Module 4: Admin Module
* Monitor total users (Owners & Renters)
* Approve or remove spam properties
* Manage transaction and booking logs
