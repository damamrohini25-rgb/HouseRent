# HouseRent - MERN Stack House Rental System

## Description
HouseRent is a MERN stack web application that helps property owners list rental properties and allows renters to search and book homes.

## Technologies Used
- React
- Node.js
- Express.js
- MongoDB
- Vite

## Modules
- Admin
- Owner
- Renter

## Features
- User Registration
- Login
- Property Listing
- Property Search
- Dashboard
- Booking Management
